# MarginFit v0.1.5 — P1-B 自适应检测路径的决策记录

日期 2026-10-09。阶段结论：**保留 0.1.4 原逐页 text-probe 检测，暂不合入文档级 raster-first**。

- 已重新审查核心规则：只有可靠证据显示某文档绝大多数页面有非文字绘图，并且真实 A/B 总 detect 时间明显减少，才启用 raster-first。
- 当前测试有合成含矢量的 PDF、纯文字、扫描页和科学论文，但 **没有完成长篇真实混合 PDF 的多轮全链路 A/B CPU 对照**；隔离 Zotero headless 测试驱动连续在启动调试器前超时，不能从现有样本证明跳过 operator-list 的 CPU 收益。
- PDF.js getOperatorList 的实际缓存与 page.render 操作存在共享；仅看单次调用耗时可能误判总体渲染成本。无充分证据不能把“5/6 页面非纯文本”转化为全书默认策略。
- 因此没有修改 src/runtime.js 的选择逻辑；对纯文字、矢量/乐谱/扫描的原有可靠分类和保护仍然有效。对扫描无文字的页面仍跳过 operator-list。
- 不推进未经证实的复杂启发式，是本阶段按计划执行“候选方案不达标则撤销/保留原方案”的结果，并非对未来优化路线的否定。
- 后续使用真实 100 页以上含图论文与乐谱，补全 A/B 基准后可以继续单独研究；无须阻断 P1-C 页码功能、P2-A 缓存 I/O 和 P2-B 几何读取优化。

本阶段完成方案复审和决定，不修改产品功能，无单独新测试。正式发布仍须在真实 Zotero 取得整套回归测试通过。
