# MarginFit：12、14、16单位逐步定位复测

日期：2026-10-16。**仅测试12、14、16 PDF单位且均不提前移动**；不测试其他余量、提前定位或异常页跨组恢复。

## 样本与方法

- 第一批76份PDF；第二批64份不同PDF。仅复用已有坐标缓存，批次间路径及文件名+字节大小无重合。
- 同一套逐步求交算法：第一张不兼容的页面立即断组并成为新组起点；只在当前横向位置不再适合已经过的页面时，才执行最小调整。防抖不得覆盖所选安全边界。
- 1000 CSS px窗口、与原版一致的初始16 PDF单位缩放保护、5%缩放防抖、倍率范围0.1至5、4px横向写入防抖。模拟PDF.js页面原生居中，非真实浏览器DOM。
