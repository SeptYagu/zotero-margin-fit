# 实现与需求映射

需求来源是仓库根目录的 `09-智能去白边阅读开关.md`。该文件作为原始需求保存，状态描述属于写作时点；当前实现状态由 README 和验证记录说明。

| 要求 | 实现 |
|---|---|
| 保留原生 Reset Zoom | `Controller` 只包装 PDFView 的 `_onChangeViewStats`，让 React 正常启用按钮；不替换按钮、图标或原生点击回调 |
| 宽度、高度、原菜单与快捷键统一 | 实例级 `zoomPageWidth` / `zoomPageHeight` 包装；原生 `zoomReset` 间接进入宽度路径 |
| 四边独立检测 | PDF 字符框与低清像素外框取并集；旋转在 PDF.js viewport 中完成 |
| 固定保护留白 | `safeBox` 显示时加 8 个 scale=1 viewport 单位；不写入原始缓存 |
| L1 六页先执行 | `Session.l1()` 串行占用检测队列，完成后发布奇偶模型 |
| L2 当前页及前后三页 | `Session.local()` 硬性等待 L1，并按向后优先顺序精算，缓存命中跳过 |
| L3 固定倍率锚点 | 只在实际写入并读取 PDF.js scale 后更新；小幅理想变化不移动锚点 |
| 滚动时不自动改视图 | 用户输入改变 epoch；稳定期请求、异步结果、定位写入都检查 epoch 与文档身份 |
| 双轴定位 | 水平按实际内容中心；主动高度适应纵向居中、主动宽度适应对齐顶部；自动适应保留当前 PDF 阅读坐标，倍率不变不写纵向位置 |
| 开关跨文档 | `extensions.marginfit.enabled`，最近方向存 `extensions.marginfit.mode` |
| 关闭不强制移动当前页 | 偏好切换使过期请求失效并刷新按钮状态，不主动改缩放或位置 |
| 禁用／卸载还原 | 保存属性描述符和继承状态；移除 Hook、监听器、定时器及工具栏；不覆盖后来其他插件的 Hook |
| 数据与文件不变 | 只读 PDF 页面，不创建新附件、不改写字节、批注或文献记录 |

## 坐标与缓存

`Braw` 存在当前页旋转后的 **scale=1 viewport** 坐标中，顺序是 `[left, top, right, bottom]`，原点左上。记录尺寸、旋转、算法版本和 PDF.js 文件指纹修订。它是绝对坐标，不是相对奇偶模型的 delta。

PDF.js `currentScale` 与实际 viewport.scale 相差 CSS 单位换算因子；缩放计算与定位必须显式考虑该因子。奇偶模型以样本原始框归一化后的保守并集表示，并标记为 prediction；不把预测宣称为其他页的精算结果。空白／背景不可信的样本使该奇偶模型退回整页。

检测画布通过 Zotero PDF.js 的 `skipBlender` 跳过阅读主题着色，读取 PDF 原始颜色；不修改可见阅读器的主题。原生和手动旋转均计入记录。模型建立时若旋转变化或与当前阅读器旋转不一致，预测暂时保守使用整页，L2 再精算当前旋转下的边界。

Session 仅在相同的、仍存活的 PDFDocumentProxy 上共享检测缓存和单并发队列。不同窗口即使打开同一附件，也可能拥有不同 PDF.js 文档实例，此时各自分析，避免一个窗口关闭后另一窗口访问已销毁的代理。视图状态始终独立。

## 异步与交互

等待 PDFView 的初始化 Promise，确保 Zotero 已执行初始阅读位置恢复。L1 完成前保持原始视图；如果此间用户未输入，则在真实当前页应用一次预测适应。500 ms 稳定期后 L2 以真实页面边界为准，每个周期最多做一次自动定位。

按 0.1.1 用户反馈修正纵向交互：初始化和停稳后的自动适应都保留视窗中心对应的 PDF 坐标，不把它夹到内容框内部，也不自动纵向对齐顶部或居中。倍率不变时完全不赋值 scrollTop，避免舍入造成微移。视窗中心位于所选页之外（例如页间间隙）时，仅检测和预读，延后自动视图适应，避免强行跳到某页；主动按钮操作仍精确对齐内容。

每个稳定周期分别记录已定位与已预读状态；主动宽／高适应完成定位不阻止随后的 L2 邻页预读。关闭识别将共享 Session 标为暂停：在途单页可以结束并入缓存，后续 L1/L2 检测不启动；未完成的 L1 不发布模型，重新开启时从已有样本继续。

用户 wheel、触摸移动、页面导航或滚动让 epoch 失效；已排队而尚未执行的旧任务直接跳过。在途分析只写缓存。插件写入视图后短暂屏蔽自己的 scroll/scale 事件；用户的 wheel、pointer 或导航键始终可以解除屏蔽、立即取消待定位步骤。

工具栏属于 Zotero 的窗口拖动区域。新增按钮采用原生 toolbar-button 类，并显式设置 -moz-window-dragging:no-drag，避免鼠标点击被窗口拖动接走；图标不参与鼠标命中，点击落到按钮上。

手动 zoom 建立新锚点，并暂时停止当前页自动适应。主动适应按钮、进入另一主要阅读页、视窗变更或切换开关可恢复自动适应。选择文本或拖动期间不执行自动适应。

## 安全回退

不可信背景、全白页、过密背景或渲染错误存 fallback 记录，L2 保持当前视图并提供简短 tooltip。不使用固定人工框替代检测；不以 L1 预测充当检测成功。检测轻微噪点时宁可多留白，不删除孤立的细字或页码。

8 单位安全留白和 800 px 上限是首版内部参数，仍需真实论文／扫描语料继续校准。长边画布像素量只表示临时图像缓冲开销，不等于 PDF.js 解析、字体、图片解码及整个进程的峰值内存。
